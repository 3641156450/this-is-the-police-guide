2.2 每天固定会发生的事

  1. 上班前结算：每个警员掷骰 Random(0,100) < 他的 Laziness → 决定是否开口请假（详见第三章）
  2. 派警：出警路上耗时 10 / 15 / 20 秒（按距离 1.125 / 1.875），现场执行 3 秒。 所以远处的案子要提前派人，别等警告亮了才动。
  3. 现场处置问答（20% 概率触发，见 8.2）——这时候才轮到文本选项登场
  4. 处理黑帮任务 / 市政厅请求（每 5 天一次市政厅）
  5. 下班结算：工资累计、精力、酗酒、政治观点变化（每天 5% 概率改立场）

2.3 一个反直觉但很重要的点

警员的精力（Energy）是消耗品，而请假是他自己补精力的手段。 精力 ≤2 时被拒绝 → TL −10。所以与其硬留一个累垮的人，不如批了（代价只是他 Laziness +7/+5/+3/+2）。

第三章 请假系统（最详细）

3.1 完整判定链【全部已验证】

每天上班前，对每个警员：

① 他会不会开口？
   掷骰 = Random(0, 100)
   若 掷骰 < 他的 Laziness  →  开口请假
   （Laziness=5 的人约 5%，Laziness=20 的人约 20%）

② 摇到什么级别的理由？
   r = Random(0, 100)
   r < 50          → Severity 1（扯淡）  50%
   50 ≤ r < 80     → Severity 2（中等）  30%
   r ≥ 80          → Severity 3（大事）  20%
   摇到 3 级 = 必定请假，不再判定

③ 你批准（SendHome）：
   TL 不变
   该警员 Laziness +=  +7 / +5 / +3 / +2（按 0/1/2/3 枚警徽）
   精力重置为 5

④ 你拒绝（DenyGoingHome）：
   if (!他喝醉) {
       if (他精力 ≤ 2)   TL += −10
       else switch(理由级别) {
            1级 → TL += −1
            2级 → TL += −7
            3级 → TL += −10
       }
   }
   该警员 Laziness +=  −7 / −5 / −4 / −5（按警徽数，变老实）

3.2 决策树（照着这个走就行）

他来请假
 ├─ 理由 Severity 3（葬礼/车祸/孩子结婚/房子烧了…）
 │     → 【批准】 拒绝要 −10 TL，批准只涨 +2~+7 Laziness，血亏 vs 血赚
 ├─ 理由 Severity 2（邻居死了/焦虑发作/抗抑郁药吃光…）
 │     → 【看 TL 余量】 拒绝 −7。TL 高（>100）可以拒，TL 吃紧就批
 ├─ 理由 Severity 1（狗狗生日/商场大促/忘喂鱼/想看完小说…）
 │     → 【随便拒】 只 −1，还能让他 Laziness −7 变勤快
 └─ 他精力 ≤2（累垮了）
       → 【批准】 拒绝就是 −10，而且他状态也不适合出警

进阶技巧：主动把高警徽的人派去"扯淡理由"的场景拒绝他——3 徽的警员 Laziness 基数低，拒绝还能倒扣 5 点，把他养成不爱请假的好员工。

第十三章 黑帮（Mafia）核心机制与刺杀触发

本节全部基于 Assembly-CSharp.dll 反编译（IL）与 GameParametersDatabase 数值库核对，非推测。黑帮对杰克有一条 0–150 的整数忠诚值（Loyalty），几乎所有黑帮互动都围绕它展开。

13.1 忠诚值（Loyalty）系统

参数 值 含义
InitialMafiaLoyalty 100 游戏开始时的忠诚
MaxMafiaLoyalty 150 忠诚上限
MafiaLoyaltyIfRefuse 50 拒绝为黑帮干活时，忠诚被直接设成 50（Mafia::OnJackAcceptedToWorkForMafia 的 else 分支）

  • Mafia::OnJackAcceptedToWorkForMafia(false)：拒绝 → 忠诚直接设成 MafiaLoyaltyIfRefuse = 50。

13.2 黑帮任务（MafiaAssignment）成败

黑帮每天会派任务（犯罪任务 / 调查任务），成败改忠诚：

任务类型 成功奖励 失败惩罚
犯罪任务（IsCrimeAssignment） MafiaCrimeAssignmentLoyaltyReward = +10 MafiaCrimeAssignmentLoyaltyPenalty = -30（× multiplier，四舍五入）
调查任务（Investigation） MafiaInvestigationAssignmentLoyaltyReward = +20 MafiaInvestigationAssignmentLoyaltyPenalty = -50（× multiplier）
  • 成功时杰克还能拿到 Reward（= OriginalReward × multiplier，见 MafiaAssignment::get_Reward → Jack::Earn）。
  • 失败时 Backlog::SetMessageProgress(3) 标记任务失败。
  • multiplier 来自 Initialize：老黑帮任务默认 0.5（惩罚/奖励减半），且 ShouldShowUp 有 50% 概率不出现（Random.Range(0,100) < 50）；沙盒模式或昏迷日之后不触发此随机。

结论：调查任务失败最伤忠诚（−50），犯罪任务失败 −30；成功则调查 +20 > 犯罪 +10。连续搞砸调查任务会把忠诚快速压穿 25 的红线。

13.3 赃物（Loot）买卖

黑帮会给你赃物去卖（Mafia::GiveLootToSell）：

  • 卖掉 → 忠诚 +MafiaLootSaleLoyaltyBonus = +20，但同时会向工会（LabourUnion::ReportIllegalActivity）举报你非法活动。
  • 超过 MafiaLootNoSaleCountDown = 14 天没卖 → 忠诚 MafiaLootNoSaleLoyaltyPenalty = -10，并触发不满。

13.4 不满（Dissatisfaction）与警告

Mafia::StartTheDay 中：若忠诚 < MafiaDissatisfactionThreshold(25) → MafiaIsDissatisfied = true，随即：

  • ShowDissatisfactionMessage（黑帮不满警告信）
  • AddCrimeTraps（往城市里埋犯罪陷阱）
  • AddCrimeAssignments（追加犯罪任务）

这相当于"黄牌"：忠诚跌破 25 就开始给你使绊子（陷阱+强制犯罪任务）。

13.5 刺杀触发：三大条件（IL 验证）

刺杀标志 MafiaWantsToKillJack 在 Mafia::InitializeNewDay 里先重置为 false，再按以下条件置 true（且黑帮未被消灭 IsEliminated 时才会真刺杀）：

条件一：忠诚归零（老黑帮的"最后通牒"）

  • 每日初始化：若忠诚 != 0 → 直接跳过刺杀分支。
  • 若忠诚 == 0 且已给过最后警告（GaveLastWarning 为真）→ set_MafiaWantsToKillJack(true)。
  • 若忠诚 == 0 但还没给过警告 → 置 GaveLastWarning=true、不满=false，并把忠诚抬到 DissatisfactionThreshold − 1 = 24（给你一次缓冲）。
  • 所以：把老黑帮忠诚压到 0 两次（或长期维持 0），就会被下定杀心。

条件二：黑帮火并连输

  • 若正处于火并（WarsOngoing）且 ConsecutiveDaysLowerPointsForOldMafia >= 3（连续 ≥3 天点数落后）→ set_MafiaWantsToKillJack(true)。
  • 火并从第 MafiaWarsStartDay = 13 天开始，持续 MafiaWarsDuration = 15 天。

条件三：调查黑帮引发杀机

  • 若忠诚 < MafiaSuspicionThreshold = 45 且 JackIsInvestigatingMafia 为真 → 每日 InvestigationKillChance += MafiaSuspicionKillChanceEachDay(3)，随后 Random(0,100) < InvestigationKillChance 命中即刺杀。
  • 即：低忠诚状态下硬查黑帮，每天约 +3% 累积刺杀概率。

13.6 刺杀发生与解除

  • 发生：DayStartScreen::GoToWorkInternal（上班出门）中，若 MafiaWantsToKillJack && !IsEliminated → 触发 GameOverDeathMessage，结局文案「杰克已死。」
  • 解除（消灭黑帮）：Mafia::Eliminate 把 IsEliminated=true（记录 DayEliminated）。调用点：
  • Gang::Close —— 端掉黑帮（完成调查 / 逮捕头目）
  • ShiftWindow::DoStorySceneAfterDismiss —— 特定剧情节点
  • 黑帮被消灭后，InitializeNewDay / StartTheDay 开头 if(IsEliminated) return，刺杀与不满逻辑全部失效。

实战建议：想避免被做掉，优先把忠诚维持在 25 以上（别让调查任务连续失败）；要么尽早端掉黑帮一劳永逸；硬查黑帮时务必把忠诚顶过 45。
